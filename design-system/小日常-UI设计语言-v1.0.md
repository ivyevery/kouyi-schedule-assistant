# 小日常 UI 设计语言 V1.0

## 设计定位

小日常是一款面向个人口译工作者的日程工具。视觉目标是：

- 柔和、轻快、有生活感
- 可爱但不幼态
- 信息清楚，适合高频查看
- 浏览页克制，操作页更有情绪
- 手机与桌面共享视觉 Token，但不强制使用相同布局

## 色彩系统

### 基础色

| Token | 色值 | 用途 |
|---|---|---|
| `bg-page` | `#FFF5F2` | 页面桃粉奶油底色 |
| `surface` | `#FFFAF7` | 卡片、输入区 |
| `surface-strong` | `#FFFDFB` | 高对比内容面 |
| `ink-primary` | `#3F3734` | 主文字 |
| `ink-secondary` | `#847773` | 辅助文字 |
| `line` | `#EADED9` | 细分割线与输入框边界 |
| `theme` | `#F2762E` | 深橙色主题、主按钮、当前导航 |
| `theme-script` | `#D95B2B` | 首页手写英文标题，保持橘红感并提高可读性 |
| `theme-soft` | `#FFF0E7` | 主题浅底 |

### 日程状态

| 状态 | 色值 | 浅底 |
|---|---|---|
| 预定 | `#F5B14D` | `#FAEAD6` |
| 确认 | `#8FC9E9` | `#E4F2F8` |
| 完成 | `#8DBB91` | `#E7F0E5` |
| 取消 | `#AAA19E` | 不主动强调 |
| 占用 | `#B184C7` | `#F5EFFF` |

状态色只表达业务状态。深橙色只表达主题、操作和当前选中状态。

## 字体

### 标题字体

```css
"Source Han Serif SC",
"Noto Serif CJK SC",
"思源宋体",
"Songti SC",
serif
```

用于：

- 页面主标题
- 日期数字
- 月份标题
- 会议名称
- Upcoming 标题

### 界面字体

```css
"Source Han Sans SC",
"Noto Sans CJK SC",
"思源黑体",
"PingFang SC",
system-ui,
sans-serif
```

用于：

- 星期与辅助信息
- 按钮和导航
- 表单标签与输入
- 状态和数据

### 手机字号

| 层级 | 字号 |
|---|---:|
| 页面主标题 | 25-28px |
| 月份或区块标题 | 18-22px |
| 会议名称 | 15-17px |
| 正文与输入 | 13-15px |
| 辅助信息 | 11-12px |
| 微型状态 | 10-11px |

宋体小于 14px 时只用于日期数字或非常短的文字。

## 间距与密度

- 基础网格：4px
- 页面左右边距：18px
- 区块间距：12-16px
- 表单字段间距：10-12px
- 首页事件行高：78-92px
- 月历列表单项：两行结构，使用细分割线
- 手机内容最大宽度：520px
- 底部安全距离：导航高度加系统安全区

首页保持舒展。月历和表单采用更高信息密度。

## 形状

- 页面模块：18-22px 圆角
- 输入框与按钮：13-15px 圆角
- 筛选标签：胶囊
- 日期：正圆形
- 底部导航：22px 圆角
- 不使用厚重边框和强阴影
- 阴影只用于浮层级关系，颜色向暖橙灰倾斜

## 页面规则

### 首页

- 首页英文区块标题使用橘红色手写花体，当前标题为 `Today`，事件区为 `Upcoming...`
- 自然周，星期在上、日期在下
- 当天或选中日期使用深橙实心圆
- 有日程的日期显示状态小圆点
- Upcoming 只显示未来的预定与确认
- 每项只显示日期、会议名和状态色
- 无日程时不生成重复占位卡
- 事件使用极浅状态底色与右侧实心状态点
- 桌面端悬停或键盘聚焦有事件的日期时，在日期下方显示浮层，不推动页面内容
- 手机端点击日期显示同一浮层；点击空闲日期不显示提示面板

### 月历

- 根据月份自动使用五行或六行
- 当月日期统一为圆形
- 空闲日期为白底细描边
- 有日程时使用状态色实心圆
- 选中日期使用贴近圆形的深橙粗描边
- 不增加状态图例和重复小圆点
- 列表第一行显示完整日期，并在右侧显示 SI/CI、地点、时长
- 列表第二行只显示会议名，保持每项严格两行
- 每条记录使用跟随状态色的纯色小话筒
- 占用不是会议状态，使用独立紫色语义
- 只有占用的日期使用紫色实心圆；会议与占用并存时，在会议状态圆下增加紫色短横线
- 月历标题区提供“标记占用”入口，长按日期也可打开同一面板
- 占用面板只包含事项、开始日期、结束日期和备注
- 点击紫色占用列表项可编辑或取消占用
- 在占用范围内保存会议时提示冲突，但允许用户确认后继续保存

### 新建日程

- 使用独立整页，不使用底部弹层
- 独立整页仍保留底部主导航，保存或取消前后都可直接切换页面
- 顶部为耳机、日历与语言气泡插图
- 快速录入区允许文字和语音
- 识别结果写入结构化表单
- 表单可滚动，保存按钮位于表单末尾

### 设置

- 顶部使用手机、电脑、云与同步箭头插图
- 云朵内放橙绿同步箭头
- 卡片按同步、本机保存、数据文件、个性化和微信导出分组
- 主操作使用深橙色
- 次级操作使用浅蓝色或白底描边
- 绿色只表达已开启或已完成状态
- 默认主题固定为深橙色

## 插画语言

- 无描边或极少描边
- 扁平、圆润、柔和色块叠加
- 不使用复杂人物场景
- 不使用高光、玻璃质感或强 3D
- 配色来自桃粉、珊瑚橙、杏黄、天空蓝和鼠尾草绿
- 浏览页只使用小型点缀
- 新建和设置使用完整顶部插图
- 插图不能遮挡正文或表单标签

## 交互与无障碍

- 点击反馈使用轻微缩放
- 键盘焦点使用主题色轮廓
- 支持系统减少动效
- 输入框标签始终位于输入框上方
- 正文和按钮达到 WCAG AA 对比度
- 固定导航不得遮挡最后一条内容
- iOS 安全区域必须预留
